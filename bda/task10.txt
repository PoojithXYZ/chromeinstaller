Start HBase: hbase shell
Create Tables with Multiple Columns: 
create 'students', 'personal', 'academic', 'contact'

Insert Data Into HBase Table:
put 'students', '1', 'personal:name', 'Alice Johnson'
put 'students', '1', 'personal:age', '22'
put 'students', '1', 'academic:department', 'Computer Science'
put 'students', '1', 'academic:marks', '89.5'
put 'students', '1', 'contact:email', 'alice@example.com'
put 'students', '1', 'contact:phone', '9876543210'

put 'students', '2', 'personal:name', 'Bob Smith'

put 'students', '2', 'contact:phone', '8765432109'

Retrieve Data from HBase Table
Fetch all records: scan 'students'


Fetch a specific row:  get 'students', '1'


Fetch a specific column value: get 'students', '2', 'personal:name'

Fetch multiple columns in a row:  get 'students', '1', {COLUMNS => ['personal:name', 'academic:marks']}


Update Data in HBase: put 'students', '1', 'academic:marks', '95.0'

Delete Data: delete 'students', '2', 'contact:email'

Using Filters in HBase: 
Retrieve students from the Computer Science department:
scan 'students', {FILTER => "SingleColumnValueFilter('academic', 'department', =, 'binary:Computer Science')"}




Retrieve students who scored more than 80 marks
scan 'students', {FILTER => "SingleColumnValueFilter('academic', 'marks', >, 'binary:80')"}

Develop a pig Latin script to count the number of words in a text file. 
nano input.txt
Hadoop is powerful
Pig is easy to use
Hadoop and Pig work together
Pig is powerful and flexible
hdfs dfs -mkdir -p t6/
hdfs dfs -put input.txt t6
nano wordcount.pig

lines = LOAD 't6/input.txt' USING TextLoader() AS (line:CHARARRAY);

words = FOREACH lines GENERATE FLATTEN(TOKENIZE(line)) AS word;

filtered_words = FILTER words BY word IS NOT NULL;

grouped_words = GROUP filtered_words BY word;

word_count = FOREACH grouped_words GENERATE group AS word, COUNT(filtered_words) AS count;

STORE word_count INTO 't6 /output' USING PigStorage(',');

pig -x mapreduce wordcount.pig
